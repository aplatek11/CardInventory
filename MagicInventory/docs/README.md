# Magic Cards

A personal collection of Magic: The Gathering decklists, card ideas, and
deck-building notes.

## Repository layout

- [`Starter Decks`](Starter%20Decks/Starter%20Deck%20-%20TMNT.md) — decklists based on existing starter
  products and themes.
- [`Custom Decks`](Custom%20Decks/1%20-%20Developing/TMNT%20Counter%20Crisis.md) — original deck concepts and works in
  progress.
- Individual card ideas can be added as they are assigned to a deck.

## Custom deck status

Custom decks are grouped by development stage:

- [`Custom Decks/1 - Developing`](Custom%20Decks/1%20-%20Developing/TMNT%20Counter%20Crisis.md) —
  actively changing decklists.

## Decklist conventions

Deck files use Markdown tables to track:

- card name and rules text
- mana cost
- ownership
- notes and possible additions

When moving a deck between development stages, preserve its filename and move
the complete Markdown file so links and history remain easy to follow.
